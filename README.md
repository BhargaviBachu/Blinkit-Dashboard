# Blinkit-Dashboard
1.Blinkit Business Insights Dashboard using Power BI & SQL

2.Short Description
Built an interactive Power BI dashboard to analyze Blinkit sales, orders, and customer trends.
Used SQL and data modeling to generate actionable business insights.

3.Tech Stack
- Power BI – Dashboard creation & data visualization
- SQL – Data extraction, cleaning, and querying
- DAX (Data Analysis Expressions) – Calculations & KPIs
- Data Modeling – Relationships, schema design (star/snowflake)
- Power Query (M Language) – Data transformation & ETL

4.Data Source
Simulated Blinkit dataset for analytics practice, including sales, orders, and customer behavior data

5.Features/Highlights
📊 Developed an interactive Power BI dashboard to monitor sales performance, order trends, and key business metrics
📈 Visualized KPIs such as total sales, revenue growth, and order volume for quick decision-making
🧩 Implemented data modeling with relationships to ensure accurate and efficient analysis
⚡ Used DAX functions to create calculated measures and dynamic insights
🔍 Enabled filters and slicers for region, product category, and time-based analysis
🔄 Performed data cleaning and transformation using Power Query for reliable reporting
📉 Identified customer behavior patterns and top-performing products
